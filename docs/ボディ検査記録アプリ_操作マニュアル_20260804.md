# ボディ検査記録アプリ 操作マニュアル

## 1. 概要

本アプリは、ボディ検査装置の検査記録を登録・管理するためのアプリケーションです。

------------------------------------------------------------------------

# 2. 起動・終了

## 起動方法

1.  デスクトップの **「ボディ検査記録アプリ」**
    ショートカットをダブルクリックします。
2.  アプリ画面が表示されれば起動完了です。

## 終了方法

ウィンドウ右上の **「×」** ボタンをクリックしてください。

------------------------------------------------------------------------

# 3. 定常作業

## 3.1 言語選択

画面上部の言語選択から以下を選択します。

-   日本語
-   English

画面表示のみ切り替わります。

------------------------------------------------------------------------

## 3.2 データ更新

1.  「データ更新」をクリックします。
2.  最新データが読み込まれます。

作業開始前に必ず実施してください。

------------------------------------------------------------------------

## 3.3 データ入力

入力方法は2種類あります。

### 手入力

各項目へキーボード入力します。

### バーコードリーダー

バーコードを読み取るだけで対象項目へ入力されます。

入力内容を確認してください。

------------------------------------------------------------------------

## 3.4 データ登録

1.  入力内容を確認します。
2.  「データ登録」をクリックします。
3.  「データ登録完了しました」と表示されたら登録完了です。

------------------------------------------------------------------------

# 4. 非定常作業

## バックアップ

定期的に実施してください。

1.  「バックアップ」をクリックします。
2.  バックアップが保存されます。

------------------------------------------------------------------------

## アラームコメント吸出し

PLC等からアラームコメントを取得します。

1.  「アラームコメント吸出し」をクリックします。
2.  完了メッセージを確認します。

------------------------------------------------------------------------

## データ出力

CSV形式でデータを出力します。

1.  「データ出力」をクリックします。
2.  取得日数を入力します。
3.  CSVがデスクトップへ保存されます。

------------------------------------------------------------------------

# 5. アラーム発生時の処置

アラームが表示された場合は次の順番で対応してください。

1.  アラーム内容を確認する。
2.  入力内容を再確認する。
3.  必要に応じて「データ更新」を実施する。
4.  再度登録を行う。
5.  解決しない場合はシステム担当者へ連絡する。

------------------------------------------------------------------------

# 6. 日常点検

-   作業開始時にデータ更新を実施する。
-   登録完了メッセージを確認する。
-   定期的にバックアップを取得する。
-   必要に応じてCSV出力を実施する。

------------------------------------------------------------------------

# 7. 操作の流れ

1.  アプリ起動
2.  言語選択
3.  データ更新
4.  手入力またはバーコード入力
5.  データ登録
6.  必要に応じてバックアップ・CSV出力・アラームコメント吸出し
7.  アプリ終了
