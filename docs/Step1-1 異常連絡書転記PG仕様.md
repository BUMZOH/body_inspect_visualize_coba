# Step1-1 異常連絡書転記PG仕様

- "データ登録"ボタンを押し、現状の処理が終わったタイミングで実施する
- "項目別不良数"の"再検査時"の値で、不良数が100個以上の項目がある場合に処理を継続(自動判断)
- "異常連絡書に転記しますか？"とユーザに確認し、"はい(またはOK)"の時に処理を継続
- アプリ同一フォルダ内のエクセルファイル"異常連絡書テンプレート.xlsx"（テンプレート）を基にする
- エクセル操作は`xlwings`を使う
- テンプレートをコピーし、コピーした日時のタイムスタンプを付加する(例: "異常連絡書_20261118_085422.xlsx")
- コピーしたエクセルファイルは"excel_output"フォルダに保存する
- コピーしたファイルをxlwingsで開き、セルへ転記していく(転記内容は今後決定)
- 現段階では動作確認のため、ダミーデータを以下の転記先へ転記する
- エクセル操作部は別モジュール"issue_abnormality_report.py"に分離する


### 転記項目と転記先
#### Excel転記先セル（テンプレート変更時はここを修正する）
```
BASIC_CELLS = {

    "record_date": "M2",
    "part_no": "C3",
    "nc_process_date": "L3",

    "remaining_checker": "V14",
    "ng_count": "C4",
    "ok_count": "H4",

```

#### (検査項目名セル, 再検査不良数セル)
```
NG_CELLS = [
```

### 注意事項
- 実機での確認ができないため、ダミーデータ(固定で1つのみ)を使用してエクセル転記部分をまず作成する
- ダミーデータはSQLite DBファイルを参考にして実際に登録されている値を使用する
- エクセル転記部分の動作確認は、プログラム起動直後に自動実行させればOK
