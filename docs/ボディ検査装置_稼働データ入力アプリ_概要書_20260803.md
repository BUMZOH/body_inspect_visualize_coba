# ボディ検査装置 稼働データ入力アプリ 概要書

------------------------------------------------------------------------

# 1. アプリ概要

本アプリは、ボディ検査装置の稼働データを入力・保存するためのデスクトップアプリである。

Pythonを中心に開発し、GUIには **pywebview** を採用している。
画面はHTML/CSS/JavaScriptで構成されており、ブラウザ技術を利用しながらネイティブアプリとして動作する。

保存先はSQLiteデータベースであり、将来的な分析やCSV出力なども考慮した構成となっている。

------------------------------------------------------------------------

# 2. システム構成

``` text
                ┌─────────────────────┐
                │      ユーザー        │
                └─────────┬───────────┘
                          │
                          ▼
                index.html
                style.css
                app.js
                          │
                          │ pywebview API
                          ▼
                     app_api.py
                          │
        ┌─────────────────┴────────────────┐
        │                                  │
        ▼                                  ▼
      db.py                     PLC・JSON設定ファイル
        │
        ▼
   SQLite Database
```

画面はHTMLで作成されているが、データ登録・取得などはPython側で実施する。

------------------------------------------------------------------------

# 3. データ処理の流れ

``` text
ユーザー入力
      │
      ▼
JavaScript(app.js)

入力チェック
      │
      ▼
window.pywebview.api.register_data()

      │
      ▼
Python(app_api.py)

入力値チェック
型チェック
必須チェック

      │
      ▼
db.insert_record()

      │
      ▼
SQLiteへ保存

      │
      ▼
PLCリセット（必要時）

      │
      ▼
JavaScript

「データ登録完了しました」
      │
      ▼
画面初期化
```

画面処理はJavaScript、業務ロジックはPython、DBアクセスはdb.pyに分離されている。

------------------------------------------------------------------------

# 5. 各ファイルの役割

## main.py

アプリの起動処理。DB初期化、AppAPI生成、pywebview起動を担当する。

## index.html

画面レイアウトを定義する。

## style.css

画面デザインを担当する。

## app.js

画面制御を担当する。

-   入力値取得
-   入力チェック
-   ボタン制御
-   Python呼び出し
-   メッセージ表示
-   画面初期化

## app_api.py

業務処理を担当する。

-   JSON読込み
-   入力チェック
-   SQLite登録
-   CSV出力
-   バックアップ
-   PLC通信
-   部品番号検索

## db.py

SQLite専用モジュール。

-   DB初期化
-   INSERT
-   SELECT
-   UPDATE

------------------------------------------------------------------------

# 6. JSONファイル

## config.json

アプリ全体の設定。

## staff.json

作業者情報。

## part_no.json

品番マスタ。

## data_definition.json

入力項目の定義（日本語名、型、必須入力など）を管理する重要な設定ファイル。

------------------------------------------------------------------------

# 7. common_lib_mw

PLC通信など、他アプリでも利用する共通ライブラリを格納する。

------------------------------------------------------------------------

# 8. 設計方針

  担当              役割
  ----------------- --------------
  HTML              画面構造
  CSS               画面デザイン
  JavaScript        画面制御
  Python(app_api)   業務処理
  db.py             DBアクセス
  SQLite            データ保存

責務を分離することで保守性・拡張性を高めている。

------------------------------------------------------------------------

# 9. 特徴

-   pywebviewを利用したデスクトップアプリ
-   HTML/CSS/JavaScriptによるGUI
-   SQLiteによる軽量DB
-   JSONによる設定管理
-   JavaScriptとPythonの役割分担
-   PLC連携
-   CSV出力・バックアップ機能

------------------------------------------------------------------------

# 10. まとめ

本アプリは「画面」「業務処理」「DB処理」を分離した3層構造を採用している。

特に **app.js・app_api.py・db.py**
を分離することで、保守性・拡張性・可読性を高めている。
