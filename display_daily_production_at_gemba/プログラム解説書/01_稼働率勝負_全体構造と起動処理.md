## 1. このアプリは何をするか

Windows上のTkinterフルスクリーンアプリ「稼働率勝負」。上段には昼勤・夜勤の各6名の写真、今週と先週の稼働時間の比率を示す2本の横棒グラフ、月～土の週間検査数を表示する。「結果表示」で基準日時を入力し、SQLiteから集計してドラムロール・棒グラフのアニメーション・結果音・写真表情変更を行う。「メンバ入替」は昼夜の担当者を入れ替える。下段の生産数・進捗・号機別生産数は現在サンプル値。ロボットGIFはアニメーションする。

**重要:** 上段の比率は「今週の稼働秒数 ÷（今週＋先週の稼働秒数）」であり、設備稼働率（稼働秒数÷予定時間）そのものではない。

## 3. 実行順序を追う

Pythonはファイルを上から読み込むが、`def` は**関数を登録するだけ**で、関数の中身はまだ実行しない。設定値・リストなどの代入は読み込み時に実行される。最後に次の部分へ到達する。

```python
if __name__ == "__main__":
    main()
```

ファイルを直接実行したときだけ `main()` を呼ぶ。別のPythonファイルからimportした場合、原則としてこの呼び出しは起きない。

```text
main()
 ├─ staff_shift_info.json を読む
 ├─ STAFF_NAMES を作る
 ├─ initialize_app()        Tkウィンドウ、ttkスタイル
 ├─ create_main_layout()    ヘッダー、上段、下段
 │   ├─ create_header()
 │   ├─ create_top_panel()
 │   │   ├─ create_staff_group() × 2
 │   │   ├─ create_ratio_section()
 │   │   └─ create_weekly_table()
 │   └─ create_bottom_panel()
 │       ├─ create_kpi_table() × 2
 │       ├─ create_progress_section()
 │       └─ create_bot_section() → animate_bot()
 ├─ setup_events()          ボタンとキー、終了イベント
 └─ root.mainloop()         ユーザー操作を待ち受ける
```

**注意:** `root.mainloop()` に入った後は、クリックやタイマーによって関数が呼ばれる。コードが毎回上から再実行されるわけではない。

## 4. `main()` の4つの仕事

```python
def main():
    global STAFF_INFO, STAFF_NAMES

    with open(STAFF_INFO_FILE, encoding="utf-8") as file:
        STAFF_INFO = json.load(file)
    STAFF_NAMES = ["NAME"] + list(STAFF_INFO["staff"].keys())

    initialize_app()
    create_main_layout()
    setup_events()
    root.mainloop()
```

1. JSONからスタッフ情報を読み、コンボボックスの選択肢を用意。
2. `initialize_app()` でTkのルートウィンドウを作る。
3. `create_main_layout()` で画面部品を作る。
4. `setup_events()` で操作と関数を結び、`mainloop()` を開始。

`global STAFF_INFO, STAFF_NAMES` は、関数内の代入をモジュール冒頭の変数に反映させる宣言。`global` はすべての変数に必要なわけではない。リストの要素を書き換えるだけなら不要で、変数自体に新しい値を代入する場合に必要。

## 5. ファイルパスの作り方

```python
BASE_DIR = Path(__file__).resolve().parent
DB_FILE = BASE_DIR / "data" / "body_inspection_machine.db"
```

`__file__` は現在のPythonファイルのパス。`resolve()` は絶対パスにし、`parent` でその親フォルダを得る。`Path` の `/` はパスの連結演算子。**実行時のカレントディレクトリに依存しにくい**書き方。

## 6. 設定値・仮データ・グローバル変数の違い

- **設定値:** `SCREEN_WIDTH`、`BG`、`FONT` など。起動中は基本的に変えない。
- **仮データ:** `actual_recent`、`machine_counts` など。下段表示のための固定値。
- **グローバル変数:** `root`、`day_group`、`ratio_targets` など。関数をまたいで参照・更新する。

```python
root = None
ratio_canvases = []
ratio_targets = [a / (a + b) if a + b else 0.5 for _, a, b in ratio_specs]
result_photo_modes = ("normal", "normal")
```

`root = None` は「ウィンドウは後で作る」という宣言。`ratio_canvases` には生成したCanvasの参照を追加する。`ratio_targets` は棒の**目標位置（0～1）**、`result_photo_modes` は `(昼勤の表情, 夜勤の表情)`。

### `ratio_specs` の構造

```python
ratio_specs = [
    ("【直近1時間】（18：00〜19：00）", 60, 40),
    ("【全経過時間】（8：00〜19：00）", 52, 48),
]
```

外側はリスト、内側は3要素のタプル。インデックス0が直近1時間、1が累積。各タプルは `(タイトル, 今週の整数%, 先週の整数%)`。初期値は仮値で、結果表示時にDB集計結果に置き換わる。

### `main` という名前が2種類ある

このソースにはグローバル変数 `main`（画面全体のFrame）と関数 `main()` が**同じ名前で存在**する。Pythonでは関数定義が名前 `main` を関数オブジェクトに割り当て、その後 `create_main_layout()` 内の `global main; main = tk.Frame(...)` が同じ名前をFrameで上書きする。直接実行時は最後の `main()` 呼び出しを評価してから関数内部でFrameに置き換えるため、通常の起動は成立するが、**起動後に `main()` を再度呼ぶことはできなくなる**。これは読みやすさ・保守性の観点から注意すべき実際の命名衝突。今後はFrame側を `main_frame` などに改名するのが妥当。今回はコード変更なし。

## 7. Tkinterの基本単位

| 要素 | 意味 |
|---|---|
| `tk.Tk()` | アプリのメインウィンドウ |
| `tk.Frame(parent)` | 他の部品を入れる箱 |
| `tk.Label(parent)` | 文字・画像を表示 |
| `tk.Button(parent)` | 押せるボタン |
| `ttk.Combobox(parent)` | 選択式入力 |
| `tk.Canvas(parent)` | 四角形、線、文字などを自由に描く領域 |
| `pack()` | 順に積むレイアウト |
| `grid()` | 行・列に配置するレイアウト |
| `place()` | 座標・割合を指定して配置 |

`parent` は「どの箱の中に置くか」。`tk.Frame(main)` はmainという親の中にFrameを作る。**同じ親の直下で `pack()` と `grid()` を混ぜない**ことが原則。異なるFrameの内部ならそれぞれ別の方式を使える。

## 8. `initialize_app()` と `setup_events()`

`initialize_app()` は `root = tk.Tk()`、ウィンドウ名、1920×1080、背景色、フルスクリーン、ttkの`clam`テーマ、Comboboxフォントを設定する。Pillowがない場合もアプリの一部は動くが写真/GIFは表示されない。

`setup_events()` は次を登録する。

```python
result_button.configure(command=show_results)
root.bind("<F11>", toggle_fullscreen)
root.bind("<Escape>", lambda event: root.attributes("-fullscreen", False))
root.protocol("WM_DELETE_WINDOW", on_close)
```

`command=show_results` は**関数を渡す**（括弧なし）。`command=show_results()` にすると登録時に即実行してしまう。`bind()` はイベント引数を受けるコールバック。`lambda event: ...` は短い無名関数。
