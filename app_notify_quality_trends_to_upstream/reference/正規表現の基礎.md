# 正規表現の基礎

Pythonでファイル名や文字列を調べるための学習テキスト

## 1. 正規表現とは

正規表現（Regular Expression）は、**文字列のパターンを表す記法**です。たとえば「数字が8桁続く」「`.csv`で終わる」「決められた形式のファイル名である」といった条件を表せます。

主な用途は次の3つです。

- **判定**：文字列がルールに一致するか調べる
- **抽出**：一致した文字列の一部を取り出す
- **置換**：一致した部分を別の文字列に変える

最初は「判定」と「抽出」だけ覚えれば十分です。

## 2. Pythonの基本形

```python
import re

pattern = re.compile(r"\d{8}")
match = pattern.fullmatch("20261111")

if match:
    print("一致しました")
else:
    print("一致しません")
```

- `import re`：正規表現の標準ライブラリを読み込む
- `re.compile(...)`：検索ルールをパターンオブジェクトにする
- `fullmatch(...)`：文字列**全体**がルールに一致するか調べる
- 一致した場合は `Match` オブジェクト、不一致の場合は `None` を返す

`r"..."` の `r` はraw文字列を表します。正規表現の `\d` や `\.` のようなバックスラッシュを扱いやすくするため、基本的に付けましょう。

## 3. 最初に覚える記号

| 記号 | 意味 | 例 |
|---|---|---|
| `\d` | 数字1文字（Unicodeの数字を含む） | `\d{2}` → 数字2文字 |
| `[0-9]` | ASCIIの数字1文字 | `[0-9]{8}` |
| `[a-z]` | a～zの1文字 | `[a-z]` |
| `[a-z0-9_]` | 英小文字・数字・`_` の1文字 | `part_1` の各文字 |
| `.` | 原則として改行以外の任意の1文字 | `a.c` → `abc` |
| `\.` | ピリオドそのもの | `\.csv` |
| `*` | 直前の要素が0回以上 | `a*` |
| `+` | 直前の要素が1回以上 | `a+` |
| `?` | 直前の要素が0回または1回 | `a?` |
| `{n}` | 直前の要素がちょうどn回 | `[0-9]{8}` |
| `{m,n}` | m回以上n回以下 | `[0-9]{1,3}` |
| `^` | 文字列の先頭 | `^abc` |
| `$` | 文字列の末尾（末尾改行直前も含む） | `csv$` |
| `(...)` | グループ化・抽出 | `([a-z]+)` |
| `\|` | どちらか一方 | `OK\|NG` |

**重要：** `*`、`+`、`?`、`{n}` は、その**直前の要素**にかかります。

```python
r"ab*"       # a の後に b が0文字以上
r"[a-z]*"    # 英小文字が0文字以上
r"[a-z]+"    # 英小文字が1文字以上
r"[0-9]{8}"  # 数字がちょうど8文字
```

## 4. `match()`・`search()`・`fullmatch()` の違い

```python
import re

text = "abc123xyz"

print(re.match(r"[0-9]+", text))       # None：先頭が数字ではない
print(re.search(r"[0-9]+", text).group())  # 123：途中でも探す
print(re.fullmatch(r"[0-9]+", text))  # None：全体は数字ではない
```

| メソッド | 判定する場所 | 使いどころ |
|---|---|---|
| `match()` | 先頭から一致するか | 先頭の形式チェック |
| `search()` | 途中を含めて一致箇所を探す | 文中の文字列検索 |
| `fullmatch()` | 文字列全体が一致するか | **ファイル名の命名規則チェック** |

## 5. 今回のPLC用CSVファイル名を読む

対象例：

```text
total_length_20261111_16.csv
bottom_thickness_20261111_18.csv
```

実際のプログラム：

```python
FILE_PATTERN = re.compile(
    r"^([a-z][a-z0-9_]*)_(\d{8})_(\d{2})\.csv$",
    re.I,
)

name = "total_length_20261111_16.csv"
match = FILE_PATTERN.fullmatch(name)

if match:
    item, day, hour = match.groups()
    print(item)  # total_length
    print(day)   # 20261111
    print(hour)  # 16
```

### 左から順に分解

| 部分 | 意味 | 一致する例 |
|---|---|---|
| `^` | 先頭 | — |
| `([a-z][a-z0-9_]*)` | 英字で始まり、その後は英数字か `_` の検査項目名 | `total_length` |
| `_` | 区切り文字 | `_` |
| `(\d{8})` | 数字8文字の年月日 | `20261111` |
| `_` | 区切り文字 | `_` |
| `(\d{2})` | 数字2文字の時 | `16` |
| `\.csv` | 拡張子 | `.csv` |
| `$` | 末尾 | — |

`re.I` は `re.IGNORECASE` の略で、大文字・小文字を区別しない指定です。`TOTAL_LENGTH_20261111_16.CSV` も一致します。

**注意：** 正規表現は形式をチェックしますが、日付の妥当性は保証しません。`20261399_99` のような値も数字の桁数だけなら一致します。後で `datetime.strptime()` で確認します。

```python
from datetime import datetime

file_hour = datetime.strptime(f"{day}{hour}", "%Y%m%d%H")
```

### `groups()` と `group()`

丸括弧 `(...)` は、値を取り出す「キャプチャグループ」です。

```python
print(match.group(0))  # total_length_20261111_16.csv（全体）
print(match.group(1))  # total_length
print(match.group(2))  # 20261111
print(match.group(3))  # 16
print(match.groups())  # ('total_length', '20261111', '16')
```

`item, day, hour = match.groups()` は、3要素のタプルを3変数にアンパックしています。

### `^` と `$` は必要？

`fullmatch()` は文字列全体の一致を確認するので、今回の使い方では `^` と `$` を省略できます。

```python
FILE_PATTERN = re.compile(r"([a-z][a-z0-9_]*)_(\d{8})_(\d{2})\.csv", re.I)
```

ただし `search()` や `match()` では意味が変わることがあるので、違いを理解するまでは元の書き方を維持しても構いません。

## 6. 正規表現を使わない方法との比較

```python
name = "bottom_thickness_20261111_18.csv"
stem = name.removesuffix(".csv")
item, day, hour = stem.rsplit("_", 2)
```

この方法でも3つの値に分けられます。ただし、**拡張子や文字数、日付の形式を厳密に確認する処理は別途必要**です。命名規則の判定と抽出を一度に行いたい今回の用途では、正規表現が便利です。

## 7. よくある間違い

1. **`.` と `\.` を混同する**：ピリオドそのものは `\.`。
2. **`*` と `+` を混同する**：`*` は0文字も許容、`+` は1文字以上必要。
3. **`search()` でファイル名全体を検証する**：途中一致するので `fullmatch()` が適切。
4. **正規表現だけで正しい日時と判断する**：日時は `datetime.strptime()` で別途確認。
5. **一致しないのに `groups()` を呼ぶ**：`None` に `groups()` はないため、`if match:` を先に書く。
6. **`\d` はASCII数字限定だと思う**：Pythonの通常のUnicode正規表現では全角数字なども一致し得る。PLCの英数字ファイル名に厳密に合わせるなら `[0-9]` を使う。

## 8. 練習問題

次の問題は、まず結果を予想してからPythonで実行してみましょう。

**問題1**：`re.fullmatch(r"[0-9]{3}", "615")` は一致する？

**問題2**：`re.fullmatch(r"[a-z]+", "total_length")` は一致する？

**問題3**：`re.fullmatch(r"OK|NG", "NG")` は一致する？

**問題4**：`re.fullmatch(r"[0-9]{2}", "123")` は一致する？

**問題5**：`total_length_20261111_16.csv` から、正規表現のグループで何が取り出せる？

**問題6**：`total_length_20261111_99.csv` は今回の正規表現に一致する？ また、日時として有効？

### 解答

1. 一致する。数字が3文字。
2. 一致しない。`_` が `[a-z]` に含まれない。
3. 一致する。`OK` または `NG`。
4. 一致しない。数字3文字は2文字指定と異なる。
5. `('total_length', '20261111', '16')`。
6. 正規表現には一致するが、99時は不正なので `datetime.strptime()` でエラーになる。

## 9. 手元で試す最小サンプル

```python
import re

FILE_PATTERN = re.compile(
    r"^([a-z][a-z0-9_]*)_(\d{8})_(\d{2})\.csv$",
    re.I,
)

names = [
    "total_length_20261111_16.csv",
    "bottom_thickness_20261111_18.csv",
    "total_length_20261111.csv",
    "memo.txt",
]

for name in names:
    match = FILE_PATTERN.fullmatch(name)
    if match:
        item, day, hour = match.groups()
        print("OK:", item, day, hour)
    else:
        print("NG:", name)
```

## 10. 最後に覚えること

- `re.compile()`：パターンを準備する
- `fullmatch()`：文字列全体を検証する
- `(...)` と `groups()`：必要な部分を取り出す
- `\d`・`[a-z]`・`*`・`+`・`{n}`：まず覚える基本記号
- **ファイル名の形式チェックと、日時の妥当性チェックは別物**

正規表現は暗記よりも、**短いパターンを1つずつ実行して確認する**のが近道です。
